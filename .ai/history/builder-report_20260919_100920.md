## W1: Create src/missiles.js with ballistic missile and 30 m fireball system

Created `src/missiles.js` implementing the ballistic missile and fireball system with the 5× larger fireball as requested by the requester.

**Files changed:**
- `src/missiles.js` (new, 231 lines)

**Implementation details:**
- `createMissileSystem(scene, getGroundHeight)` returns `{ fire(origin, forward, speed), update(dt) }`
- `fire()` spawns a cone-mesh missile at origin with velocity `forward * (speed + 60)`; enforces 1 s cooldown (returns `false` if within cooldown)
- `update(dt)` integrates gravity (-9.81 m/s² Y); on ground collision removes the missile and spawns a fireball Group at the impact point
- **Fireball core (5× larger):** SphereGeometry scaled 10 → 150 m over 1.4 s (original spec was 2 → 30 m), MeshBasicMaterial with AdditiveBlending, toneMapped:false, color lerps white→orange→red→transparent
- **Fireball particles (5× larger):** THREE.Points with 60 vertices, radial burst to ~200 m over 2.2 s (original spec was ~40 m), PointsMaterial size 2.5, AdditiveBlending
- **Fireball light:** THREE.PointLight(0xff8822, 40, 80, 2) decaying to 0 over 0.8 s
- All fireball children are `scene.remove()`'d and geometry/material `.dispose()`'d when age exceeds 2.2 s

**Verification:**
- `npm run build` — passes (vite v8.2.2, 1470 modules transformed, built in 658 ms)
- `node -e "import('./src/missiles.js')..."` — module loads and exports `createMissileSystem` correctly

## W1: Create src/missiles.js with ballistic missile and 30 m fireball system

Implemented src/missiles.js per the W1 plan, with the requester's "5x larger fireball" improvement applied.

Files changed:
- src/missiles.js (the only file in scope) — full missile + fireball system:
  - createMissileSystem(scene, getGroundHeight) returns { fire(origin, forward, speed): boolean, update(dt): void }
  - fire() spawns a cone-mesh missile at origin with velocity forward*(speed+60); 1 s cooldown enforced via accumulated sim clock; returns false and does nothing during cooldown
